\section{Introduction}
\label{sec:intro}

Dense grounded understanding requires models to connect language with fine-grained visual outputs such as pixel-accurate masks over images and videos.
Recent systems (e.g., Sa2VA) achieve this by coupling a multimodal large language model (MLLM) with a strong segmentation foundation model: the MLLM interprets user instructions and generates intermediate guidance that steers the segmentation model.
While effective, this paradigm is expensive because dense grounding benefits from high-resolution visual representations and long spatiotemporal contexts, leading to large visual token budgets that inflate memory footprint and latency.

This paper asks a practical question: \emph{can we reduce the number of visual tokens entering the MLLM while preserving (or even improving) the quality of the \texttt{[SEG]} tokens that guide segmentation and the downstream conversation}? Our answer is affirmative: we learn a token selector that preserves features most helpful for generating accurate \texttt{[SEG]} tokens (segmentability cues understood by SAM2), while still supporting Sa2VA's multimodal outputs. For compatibility, selection is applied on Sa2VA's unified image/video+VP stream after fusion and before the MLLM, but the contribution is the learned retention for \texttt{[SEG]} quality rather than the fusion itself.

\paragraph{Challenges.}
Token pruning in dense grounded settings is non-trivial for three reasons.
First, Sa2VA is inherently multi-task: selection must support both segmentation-oriented supervision (mask quality) and conversation-oriented supervision (language modeling), which can produce competing gradients.
Second, Sa2VA inputs contain heterogeneous visual evidence, including VP-conditioned tokens created from user prompts (points/boxes/scribbles), so selecting tokens on the \emph{fused} stream differs from VQA-only pipelines even though the main goal is to retain evidence that improves \texttt{[SEG]} generation.
Third, discrete Top-$k$ pruning is non-differentiable; a naive training/inference mismatch may harm stability and final quality.

\paragraph{Our approach.}
We identify the \emph{unified visual token stream} in Sa2VA as the right intervention point for efficiency: it is the first place where long-context image/video evidence and VP-conditioned evidence co-exist and directly drive \texttt{[SEG]} token generation.
Sa2VA-Dev places a budgeted selection module at this interface (``append-then-select'') so the selector can learn which features most improve \texttt{[SEG]} quality before pruning, while the downstream MLLM sees a shorter context.
We train the selector with a differentiable Top-$k$ surrogate and a curriculum-weighted constraint to reduce the train--test gap between soft gating (training) and hard Top-$k$ pruning (inference), while keeping Sa2VA's multi-task decoding unchanged.

\paragraph{Results preview.}
On Sa2VA-1B, retaining only the top 30\% visual tokens improves the overall multi-task average to 102.9\% of the baseline, with gains on referring video segmentation (MeViS: 41.7$\rightarrow$47.6; ReVOS: 47.6$\rightarrow$51.3).
We also observe reduced peak GPU memory (2.76$\rightarrow$2.46 GB) and faster prefill (40.16$\rightarrow$35.14 ms) at 30\% retention.

\paragraph{Contributions.}
\begin{itemize}
    \item \textbf{Learning to preserve \texttt{[SEG]}-critical evidence.} We formulate token selection for dense grounded understanding with the explicit goal of improving \texttt{[SEG]} token quality (segmentability cues for SAM2), while keeping Sa2VA's multi-task interface unchanged.
    \item \textbf{Train--test aligned budgeted selection under multi-task supervision.} We provide a training pipeline with differentiable budgeted gating and a curriculum constraint that improves robustness when switching to inference-time hard Top-$k$ pruning.
    \item \textbf{Empirical and efficiency evaluation.} We evaluate across image/video referring segmentation and efficiency profiling under multiple retention ratios, and include a protocol (with placeholders where needed) to verify that pruning does not degrade general multimodal conversation ability.
\end{itemize}
