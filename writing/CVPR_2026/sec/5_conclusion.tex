\section{Conclusion}
\label{sec:conclusion}

We presented Sa2VA-Select, a compatible extension of Sa2VA for studying learnable visual token selection in unified dense grounded image and video understanding.
Unlike VQA-style compression settings, Sa2VA-Select must preserve visual evidence for both language generation and segmentation-sensitive \texttt{[SEG]} token prediction.
By applying a learnable selector to the fused image/video+VP stream before the MLLM, and by using differentiable training-time selection with inference-time hard Top-$k$ pruning, our method provides a controllable way to trade visual token budget for efficiency.
Across image/video segmentation, multimodal conversation, and efficiency profiling, our current results suggest that moderate token reduction can preserve the baseline's unified-task capability and improve selected dense grounding benchmarks.

\paragraph{Limitations and future work.}
This study is an initial step toward efficient unified dense grounding, and several aspects remain to be strengthened.
First, the current evaluation focuses on Sa2VA-1B and a limited set of retention ratios; larger backbones and more diverse budgets should be evaluated in future work.
Second, although we observe favorable trade-offs, a more detailed analysis of selected versus discarded tokens is needed to explain what visual evidence the selector preserves.
Third, the current profiling focuses on memory, prefill time, and end-to-end latency under a fixed evaluation setting; broader system-level profiling would clarify deployment behavior under different decoding and video-length conditions.
Finally, extending the evaluation to domain-specific high-resolution scenarios, such as remote sensing imagery, is a promising direction for validating the practical value of learnable token selection beyond existing generic benchmarks.
