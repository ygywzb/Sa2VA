\section{Related Work}
\label{sec:related}

We review three lines of work most relevant to this paper: dense grounded multimodal understanding, visual token compression, and learnable token selection.
Compared with prior work, our setting is more constrained because token reduction must preserve both segmentation-oriented outputs and conversation ability in a unified image-video model.

\paragraph{Dense grounded multimodal understanding.}
Recent MLLMs have achieved strong vision-language reasoning, but dense grounding requires them to support pixel-level outputs rather than only text answers.
Sa2VA is a representative unified model in this direction: it combines SAM2 with an MLLM, unifies text, image, and video into a shared token space, and uses the language model to generate instruction tokens that guide SAM2.
This design supports a broad range of image and video tasks, including referring segmentation and conversation, but it also makes the visual token budget especially important because the unified stream must carry both long-context visual evidence and prompt-conditioned evidence.
Our work builds on this setting and asks whether the unified stream can be compressed without sacrificing dense grounding quality.

\paragraph{Visual token compression in MLLMs.}
Visual token compression aims to reduce the number of tokens processed by the LLM while preserving task performance.
Earlier methods often rely on heuristic rules, fixed compression ratios, or backbone-specific pruning criteria, which can be brittle under aggressive budgets.
VisionSelector is closely related to our goal: it formulates token compression as a lightweight plug-and-play decision process with a decoupled importance scorer, a differentiable Top-$k$ mechanism, and curriculum annealing to bridge the training-inference gap.
Its reported gains on image and video understanding tasks show that learnable selection can outperform heuristic compression, especially at low retention rates.
Our work differs in the target setting: instead of compressing a VQA-style MLLM, we study whether the same idea remains effective on Sa2VA's unified dense grounding stream, where preserving \texttt{[SEG]}-critical evidence is essential.

\paragraph{Learnable selection for unified dense grounding.}
Token selection in Sa2VA is not the same as token selection in standard multimodal question answering.
Sa2VA must jointly handle segmentation and conversation, and its visual input includes both image/video tokens and visual-prompt-conditioned tokens.
This makes the selection problem more sensitive to local evidence and more tightly coupled to downstream mask quality.
Our method adapts the learnable selection idea to this setting by operating on the fused visual stream before the MLLM and optimizing the selector with the same dense grounding supervision used by the baseline.
In this sense, our contribution is an application and evaluation of learnable token selection in a more demanding unified setting, rather than a new compression paradigm from scratch.
